# Изменения

## 0.4.0 — рабочая автораскладка и новый интерфейс

- Исправлено первое слово после `Alt+Shift`, `Ctrl+Shift`, `Win+Space` и смены фокуса.
- После `ghbdtn → привет` программа действительно переключает активное поле на RU; обратное направление переключает на EN.
- Backspace после замены возвращает исходный текст и прежнюю раскладку.
- Добавлен сквозной тест настоящего клавиатурного хука, замены в поле и смены HKL.
- Новый компактный светлый интерфейс с рабочими страницами «Главная», «Настройки» и «О Правке».

## 0.3.1 — исправление фраз в неверной раскладке

- Правка больше не переключает раскладку Windows после первого исправленного слова.
- Фразы исправляются последовательно: `xnj ltkftim` → `что делаешь`.
- Поле ввода повторно проверяется в момент пробела, а фоновая проверка больше не стирает набираемое слово.

## 0.3.0 — умнее и нормально выглядит на 4K

- Настоящее DPI-масштабирование: карточки, текст и кнопки больше не перекрываются.
- Общий поиск одной или двух ошибок по частотному словарю.
- Перестановки, соседние клавиши и двойные заглавные.
- Исправление раскладки проверено живым вводом: `ghbdtn` → `привет`.
- Backspace сохраняет пользовательское исключение между запусками.
- Исправлен ввод после `Ctrl+A` и Backspace.

## 0.2.0 — исправления в любых обычных полях

- Подключение к редактируемым полям через Windows Accessibility.
- Замена через безопасный RichEdit API или помеченный синтетический ввод.
- Проверка по пробелу и знакам препинания.
- Новый компактный интерфейс и собственная иконка EXE/трея.
- Исправлена ошибка `дила` → `дела`.

## 0.1.1 — подготовка публичного preview

- Поиск опечаток в словах от четырёх букв, с учётом соседних клавиш.
- Регрессионные примеры `деоа → дела` и `слвоо → слово`, без готовых правил для этих пар.
- Однократная замена слова через RichEdit вместо быстрой имитации ввода букв.
- Отмена последней замены по Backspace.
- 34 теста движка, скрипты сборки, проверки и подготовки архива.
- Документация реальной совместимости, лицензия кода и атрибуция данных.

Статус: ранний прототип для Блокнота. Другие приложения не подключены; контекстного ИИ-исправления нет.
