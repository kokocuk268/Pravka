# Third-party data

## FrequencyWords / OpenSubtitles 2018

- Creator and repository maintainer: **Hermit Dave**.
- Source: [FrequencyWords](https://github.com/hermitdave/FrequencyWords), based on [OPUS OpenSubtitles 2018](https://opus.nlpl.eu/OpenSubtitles.php).
- Content license: **Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)**. The full text is included as [`data/LICENSE-CC-BY-SA-4.0.txt`](data/LICENSE-CC-BY-SA-4.0.txt).
- Download dates: 2026-09-05 for `ru_50k.txt` and `en_50k.txt`; 2026-09-06 for the source `ru_full.txt` used below.

The distribution contains the upstream `ru_50k.txt` and `en_50k.txt` files unchanged.

`data/ru_recognition_150k.txt` is an adapted subset of upstream `content/2018/ru/ru_full.txt`. It was generated by reading entries in frequency order, keeping the first 150,000 unique lowercase words made only of Russian letters, then omitting entries already present in `ru_50k.txt`. The result contains 101,751 additional lines and remains available under CC BY-SA 4.0. The exact transformation is implemented in [`tools/build-recognition-dictionary.ps1`](tools/build-recognition-dictionary.ps1).

Exact hashes of all distributed data files are recorded in `data/SHA256SUMS.txt`. Keep this notice and the dataset license when redistributing the word lists. No endorsement by the data creators is implied.

The MIT license in the project root applies to Pravka code and the project-owned `corrections.txt` and `protected_words.txt`, not to FrequencyWords data.
