# Проверка

Последний релиз проверен на Windows 11 x64 при масштабе 250%.

## Автоматически

```powershell
.\build.ps1
.\verify-data.ps1
.\test.ps1
.\quality-test.ps1
.\integration-test.ps1
```

- `verify-data.ps1`: 6/6 файлов данных совпадают с опубликованными SHA-256.
- `test.ps1`: 87/87 проверок движка и состояния ввода.
- `quality-test.ps1`: 17/17 условий, 6 000 сгенерированных случаев RU/EN.
- `integration-test.ps1`: 15/15 сквозных проверок фокуса, настоящего клавиатурного хука, замены текста, переключения HKL, `Ctrl+A` и универсального UI Automation-пути для браузерных полей.

Стресс-тест берёт 1 000 частых русских и 500 английских слов. Для каждого он проверяет перестановку букв, пропуск, двойную букву и неизменность правильного слова. Ошибочных автоматических замен в этой выборке быть не должно.

## Проверяемые примеры

| Набрано | Результат |
| --- | --- |
| `ghbdtn ` | `привет ` + раскладка RU |
| `xnj ltkftim ` | `что делаешь ` |
| `руддщ ` | `hello ` + раскладка EN |
| `првиет ` | `привет ` |
| `малако ` | `молоко ` |
| `wrold ` | `world ` |
| Backspace после замены | исходное слово + сохранённое исключение |

Перед выпуском те же сценарии выполняются в поле Правки и внешнем Блокноте. Три страницы интерфейса отдельно рендерятся в PNG, чтобы проверить обрезку и перекрытия при высоком DPI.
