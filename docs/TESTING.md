# Проверка

Среда последнего прогона: Windows 11 x64, системный масштаб 250%.

## Автоматически

```powershell
.\build.ps1
.\test.ps1
```

Проходят **58 тестов движка и состояния ввода**:

- RU/EN опечатки;
- одна и две ошибки: `wrold → world`, `пирветт → привет`, `becasee → because`;
- раскладка: `ghbdtn → привет`, `xnj ltkftim → что делаешь`, `руддщ → hello`;
- регистр: `ПРивет → Привет`;
- правильные слова, адреса, числа и код остаются без изменений;
- отключение функций и пользовательское исключение.

Отдельно `integration-test.ps1` запускает настоящее поле WinForms, глобальный клавиатурный хук и физические VK-события. Проверяются 9 сквозных условий:

- `ghbdtn → привет` через настоящий хук;
- первое слово сразу после фокуса и `Alt+Shift`: `xnj → что`;
- фактическая смена языка поля EN → RU;
- продолжение физическими клавишами: `ltkftim → делаешь`;
- обратное исправление `руддщ → hello`;
- фактическая смена языка RU → EN;
- английская опечатка `wrold → world` без лишней смены языка.

## Ручной smoke-тест

Перед релизом повтори этот сценарий в тестовом поле Правки, Блокноте и нужном браузере:

| Набрано | Результат |
| --- | --- |
| `ghbdtn ` | `привет ` |
| `xnj ltkftim ` | `что делаешь ` |
| `wrold ` | `world ` |
| `дила?` | `дела?` |
| `becasee ` | `because ` |
| Backspace после замены | исходное слово + сохранённое исключение |

Интерфейс отдельно проверен при высоком DPI: окно, подписи, переключатели и кнопки помещаются без перекрытий.

Для нового приложения проверь обычное поле вручную. Некоторые нестандартные редакторы не публикуют фокус через Windows Accessibility.
