# Выпуск на GitHub

1. Загрузи содержимое корня проекта в новый репозиторий.
2. Выполни `.\package.ps1`.
3. Создай Release с тегом `v0.4.1`.
4. Прикрепи `dist/Pravka-0.4.1-win-x64.zip` и `dist/SHA256SUMS.txt`.

Не добавляй `.build`, `dist`, `settings.txt` и `exceptions.txt`: они уже находятся в `.gitignore`.

Описание репозитория:

> Бесплатный локальный автокорректор и переключатель RU/EN для Windows.

Темы: `windows`, `csharp`, `winforms`, `autocorrect`, `keyboard-layout`, `russian`.

Код имеет лицензию MIT. Словари распространяются отдельно по CC BY-SA 4.0; сохраняй `THIRD_PARTY_NOTICES.md` и лицензию в папке `data`.
